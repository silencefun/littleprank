# littleprank — 假屏幕与整蛊特效展示集

从 [littleprank.com](https://littleprank.com)（一个好玩、无恶意的整蛊工具站）提取的一组**零依赖、纯前端**特效演示。

每个子文件夹是某一类效果的独立展示，直接用浏览器打开文件夹内的 `index.html` 即可，无需构建、无需安装。

![littleprank 特效展示](preview.png)

## 展示列表

| 分类 | 演示 | 说明 |
|------|------|------|
| 📱 手机（假手机） | [fake-ios-update](fake-ios-update/) | iOS 更新界面、假通知、电量/充电整蛊等 |
| 💻 系统（假系统） | [fake-bsod](fake-bsod/) | 蓝屏死机、报错弹窗、假屏幕等 |
| 🪟 Windows（更新与登录） | [fake-windows-update](fake-windows-update/) | Windows 10/11 更新界面、登录与启动整蛊、激活锁等 |

每个文件夹内的 `README.md` 都包含完整源码，以及 littleprank.com 上同类工具的**一键直达**列表。

## 在线站点
